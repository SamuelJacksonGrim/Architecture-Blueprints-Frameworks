# QUICKSTART

**You don't need to know how to code.**

---

## 1. Say what you want

Plain English. Vague is fine:

> *"Build me an app that tracks when I last watered each of my houseplants."*

You are not asked to design it. You will not be asked to approve each file.

## 2. Point an AI at this repo

> *"Build the plant-watering app using this repo. Read AGENTS.md first."*

It runs the construction pass. Then you look at what it made.

## 3. Inspect the result

You get a project, a summary, and an honest note about whether the main path
ran. Accept, reject, modify, or redirect. That is authority after the pass —
not supervision during it.
