# System Flow — Plan-and-Execute

```
Goal ─▶ PLAN (make the whole step list once)
            │
            ▼
        ┌─ step 1 ─▶ ACT ─▶ OBSERVE ─┐
        │                            │ on track?
        ├─ step 2 ─▶ ACT ─▶ OBSERVE ─┤── yes ──▶ next step
        │                            │── no ───▶ REPLAN (revise remaining steps)
        └─ step N ─▶ ACT ─▶ OBSERVE ─┘
            │
            ▼
        SYNTHESIZE all results ─▶ Answer ✅
```
